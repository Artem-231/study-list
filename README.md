# Учебный список

Список дел с датами для второй лабы по вебу.

## Что можно сделать

- Создать задачу с датой и позже исправить её в той же строке.
- Поставить галочку или удалить запись.
- Найти название и отобрать дела на нужный день.
- Отсортировать по сроку в обе стороны.
- Расставить задачи вручную.

Для перестановки нужно сбросить условия и выбрать «Мой порядок».
Можно тянуть за ползунок или нажимать "Выше" и "Ниже". Верхняя половина строки означает вставку перед ней,
нижняя - после. Порядок сохраняется вместе с задачами.

Для хранения использован localStorage. Если браузер не даст сохранить список, на странице будет сообщение.
Выбранные фильтры при обновлении сбрасываются. На другом устройстве будет свой список.

Разметку создаёт `js/app.js`, оформление задаётся в `css/style.css`.
Варианты фильтров и сортировки лежат в `js/data.js`.
