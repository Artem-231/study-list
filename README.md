# Учебный список

Список дел с датами для второй лабы по вебу.

## Что можно сделать

- Записать дело и срок.
- Исправить название или дату прямо в строке.
- Отметить выполнение галочкой.
- Удалить ненужную запись.

Правки применяются кнопкой "Сохранить". "Отмена" оставляет задачу как была.
Пока всё хранится в памяти страницы: обновление очистит список.

Разметку создаёт `js/app.js`, оформление задаётся в `css/style.css`.
