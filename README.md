# Учебный список

Список дел с датами для второй лабы по вебу.

## Что можно сделать

- Добавлять, менять и удалять задачи.
- Отмечать выполненные дела.
- Искать название, выбирать состояние и день.
- Показывать сначала ближайшие или дальние сроки.

Задачи теперь сохраняются после обновления. «Мой порядок» возвращает порядок добавления;
двигать строки вручную пока нельзя.

Для хранения использован localStorage. Если браузер не даст сохранить список, на странице будет сообщение.
Выбранные фильтры при обновлении сбрасываются. На другом устройстве будет свой список.

Разметку создаёт `js/app.js`, оформление задаётся в `css/style.css`.
Варианты фильтров и сортировки лежат в `js/data.js`.
